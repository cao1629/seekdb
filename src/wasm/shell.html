Using the shell

Each tab runs its own seekdb database in a Web Worker; SQL never leaves this browser. The Storage menu chooses where the data lives: in memory, discarded on reload or close, or in this browser's origin private file system (OPFS), kept across reloads and opened by one tab at a time.

Enter
Run SQL ending in a semicolon.
Ctrl / ⌘ + Enter
Run SQL with or without a final semicolon.
Shift + Enter
Add a new line.
↑ / ↓
Browse history at the first or last line.
Escape / Ctrl + C
Cancel a query. The session reconnects; uncommitted changes roll back and session settings reset.
Ctrl + L
Clear output. Your tables and history stay.
\help help \clear clear output \tables show tables \databases show databases

Statements in a batch run in order and stop on the first error. Results show up to 500 rows and 100 columns, with a limit on displayed text. Use LIMIT for large queries. Use backticks for quoted identifiers; ANSI_QUOTES, DELIMITER, and stored-program scripts are not supported.
